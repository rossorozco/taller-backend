# Evidencias de funcionamiento

Guardar en esta carpeta las capturas de pantalla (PNG) tomadas con el sistema en ejecución. Nombres sugeridos:

| Archivo | Qué debe mostrar |
|---|---|
| `01_dashboard.png` | Inicio con las tarjetas de resumen y el listado de próximos servicios. |
| `02_propietarios.png` | Lista de propietarios (individuales y empresas). |
| `03_vehiculos.png` | Lista de vehículos y búsqueda por placa. |
| `04_placa_duplicada.png` | Mensaje de error al registrar una placa repetida. |
| `05_km_menor.png` | Mensaje de error al ingresar un kilometraje menor al último. |
| `06_orden_detalle.png` | Orden con servicios y botón para avanzar de estado. |
| `07_orden_sin_servicios.png` | Error al terminar una orden sin servicios. |
| `08_historial_vehiculo.png` | Detalle del vehículo con su historial de servicios. |
| `09_alertas.png` | Alertas: vencidos, próximos a 7 días y próximos a 30 días. |
| `10_notificaciones.png` | Recordatorios generados y marcados como enviados. |
| `11_docker_up.png` | Terminal con `docker compose up --build` en ejecución. |
| `12_pruebas.png` | Resultado de `python manage.py test` (todas las pruebas en OK). |
| `13_git_log.png` | Resultado de `git log --oneline`. |
